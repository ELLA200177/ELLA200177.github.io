03 · 产品设计

三个关键设计决策

决策一：三层分类体系，而不是让 AI 乱归

现有文件夹 + 用户自定义分类 + AI 积累的分类，三层合并去重后作为候选。AI 新建的分类会按文件夹持久化，下次自动复用——既尊重用户已有的习惯，又让 AI 能「越用越懂」。

决策二：归档前确认 + 一键撤销，把「信任」做进产品

移动文件是不可逆操作。所以设计成「预览解耦、归档显式确认、出错一键还原」——用户敢用，产品才成立。

决策三：本地模型（隐私模式）——给敏感文件的第二条路

同一套 OpenAI 兼容接口，既支持云端服务商（DeepSeek/Kimi/智谱…），也支持本地 Ollama。整理涉密文件时，AI 完全在本机运行，内容不上传。这是「把隐私作为产品功能」而不只是合规项。

04 · 隐私与安全

把「安全」做成可讲的设计

一个会移动你文件的工具，安全和隐私不是加分项，是底线。这里有两张表可以说清。

模式文件内容去向
本地模型（Ollama）不离开你的电脑
云端服务商（DeepSeek/Kimi…）发送给该服务商服务器
关键安全设计

API Key 只存本机 ~/.fileai/config.json，不进仓库；文件名与文件夹名写盘前统一清洗（非法字符、长度、Windows 保留名、路径穿越防护）；老配置自动迁移，读失败不报错。
